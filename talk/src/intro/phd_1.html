Background · Paper 1 · xAI 2023 (Springer CCIS 1902)

Compare-xAI: explainers, tested like software

Question: which explanation method can you trust, and for what?

Method: each test isolates one failure mode on a model whose true explanation is known

Finding: no popular explainer is reliable on all four dimensions, so build transparency in at design time

Also: open source, web app, 12-workflow CI; data valuation follow-ups (LossVal, KNN-Shapley O(2ᴺ) → O(TN²))

Backup (on questions). Compare-xAI unifies functional tests for post-hoc explainers (LIME, SHAP, Integrated Gradients, …) into four practitioner dimensions: fidelity, fragility, stability, stress. Each test isolates one failure mode against a known ground truth. No popular explainer is reliable across all dimensions.
