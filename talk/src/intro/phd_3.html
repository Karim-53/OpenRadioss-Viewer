Autodidact Agent: an LLM agent that teaches itself

Problem: experts' methods are never written down; an off-the-shelf LLM has the maths but not the method

Idea: the agent generates and solves its own exercises from archived reports, and stores solved cases in memory

No fine-tuning: it specialises through memory, not weights, so there is no catastrophic forgetting

Backup. Autodidact Agent (Belaid, Hecken, Rabus, Hüllermeier; in submission). Explorer: mines candidate cases from raw, unstructured material. Retriever: LLM-free feature-wise retrieval over multilingual BGE embeddings in an editable external memory. AIMBE trainer: allocates a fixed compute/API budget by adaptive influence maximisation on a skill-dependency graph, with a greedy (1−1/e) approximation guarantee. Beats GPT-5, GPT-5+RAG and DS-Agent on mechanical-engineering and cardiology (PhysioNet ECG) benchmarks under modest budgets; at Porsche, 60% → 80% on questions that take an engineer 2–3 days. It specialises through memory instead of weight updates, so there is no catastrophic forgetting.
